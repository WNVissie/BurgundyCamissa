
# Scope of Work — Employee Shift Roster Management System

Date: 2025-10-20  
Prepared for: [Client Name]  
Prepared by: SMART Project Partners (Pty) Ltd

## 1. Scope & Deliverables
**Included:**
- Create & approve shifts
- Generate timesheets from roster + approvals
- Leave log & approval
- Basic roles/admin
- Basic reporting
- Deployment to agreed environment (Netlify for frontend, Render for backend)

**Deliverables:**
- Deployed app instance (Netlify + Render)
- Admin quick-start (PDF)
- Environment variable template
- Backup/runbook summary

**Out of scope:**
- New modules, payroll/SSO integrations, native mobile apps, advanced/custom reports, bulk data migration, and third-party messaging (SMS/WA) unless listed in the quote.

## 2. Acceptance & Testing
Acceptance when:
1. The app is reachable (deployed and accessible)
2. Users can create/approve shifts, generate timesheets, and log/approve leave
3. No Severity-1 defects remain
4. The client signs acceptance or 7 days elapse from delivery without a blocking issue

## 3. Commercials & Payment
- Once-off build fee: **R10,000** (excl. VAT and third-party provider fees)
- 50% on order/acceptance, 50% on acceptance (or 7 days after delivery, whichever first)
- Invoices payable within 7 days
- Quote valid 14 days
- SMART Project Partners responsible for Netlify/Render costs for 2 weeks (1 week testing, 1 week issue resolution); client responsible for costs thereafter

## 4. Issues & Change Requests
- Client has 1 week (5 working days) to submit issues on the current scope
- Enhancements beyond scope: time-and-materials (R350/hr first 3 months, then R500/hr)
- Changes require a signed mini-SOW

## 5. Hosting & Backups
**Option 1 (client-hosted):** client owns provider accounts, credentials, and monthly bills; third-party outages are out of scope
**Option 2 (Docker to local server):** client manages OS patches, TLS, monitoring, uptime. Backups: weekly logical backups with 7-day retention; one quarterly restore test under an active support retainer
**Option 3 (client-hosted SaaS):** payment of monthly fee for using app

## 6. Warranty
30-day defect warranty on in-scope features (bug fixes only; no new features)

## 7. Support Retainer (Optional)
R5,000/month; 1 hour/day Mon–Fri (non-accumulating). Includes backups monitoring, bug-triage/fixes, environment checks, admin queries, short training/re-training, and planned maintenance. Extra time billed at R350/hr (first 3 months), then R500/hr.
